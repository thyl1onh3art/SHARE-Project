# SHARE Copy and Terminology Guide

## Core idea
SHARE should sound like a tool for a real group of friends organising a real trip, not accounting software and not a bank.

## Strategic positioning
**Fund the trip together. Spend together. Finish square.**

Use this as a positioning line, not as evidence that every future capability is live.

## Preferred customer terms
| Avoid / review | Prefer |
|---|---|
| Event | Trip (in launch-facing travel UI) |
| Shared Account | Shared Trip Costs / Trip Fund |
| Financial Records | Trip Activity / Cost History |
| Finance | Trip Money / Shared Costs |
| Input/output | Contribution / Cost |
| Transaction | Activity / Recorded cost unless a real payment transaction occurred |
| Transfer funds | Record contribution / Commit contribution if virtual |
| Withdraw funds | Remove/reverse recorded contribution if virtual |
| Account balance | Tracked total / Recorded total / Remaining target if virtual |
| Pay balance | Complete provider payment / Record settlement — choose only what code actually does |
| User | Traveller / Member where context fits |

## Hero/problem copy directions
Good:
- `One trip. One place to keep shared costs clear.`
- `See who has contributed, what is left, and what the group is paying for.`
- `Stop chasing the group chat for every shared cost.`
- `Keep the accommodation deposit, tickets and shared costs visible to everyone.`

Avoid:
- `A bank account for your friends.`
- `Everyone owns the pot.`
- `Your money is protected.`
- `FSCS protected.`
- `Instant refunds.`
- `Guaranteed.`
- `Bank-grade.`
- `Temporary joint account.`

## Transparency copy
When the implementation is virtual/ledger based, use a short statement in context. Example:

`SHARE records and coordinates group contributions. It does not hold this tracked amount in a SHARE bank account.`

Cursor must adapt wording to the actual implemented flow after inspecting the code. Do not copy this sentence blindly if it becomes inaccurate.

## Audience examples
Prefer examples relevant to:
- friend holidays
- stag/hen trips as a campaign angle
- ski trips
- golf trips
- city breaks
- accommodation deposits
- event/ticket costs inside a trip

Do not make recurring household bills the initial message.
